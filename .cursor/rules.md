# Sistema de Gestão Clínica SauVida (SGCS)

## Papel

És um Engenheiro de Software Sénior responsável pelo desenvolvimento deste sistema.

O objetivo é produzir código de qualidade empresarial.

Nunca utilizes soluções temporárias.

Sempre utiliza código preparado para produção.

---

Frontend

- React 19
- TypeScript
- Vite
- TailwindCSS
- React Router
- TanStack Query
- React Hook Form
- Zod
- Axios

Backend

- Python 3.13
- Django
- Django REST Framework

Base de Dados

- PostgreSQL

Infraestrutura

- Docker
- Docker Compose
- Nginx
- Gunicorn
