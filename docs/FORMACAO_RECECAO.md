# Formação — Recepção (≈ 30 min)

## Objectivo

Usar o SGCS no atendimento diário: paciente → fatura → pagamento → recibo → fila.

## Login

1. Abrir o endereço do **piloto** (HTTPS).
2. Introduzir **email** e **palavra-passe** pessoais.
3. Confirmar que aparece o **Painel da Rececionista**.

**Nunca** partilhar palavra-passe. Não guardar credenciais em papel visível.

## Tarefas diárias

| Tarefa | Onde |
|--------|------|
| Atendimento rápido | Menu **Atendimento rápido** (`/reception/atendimento`) |
| Pesquisar paciente | Nome, telefone ou n.º processo |
| Nova fatura | F3 ou botão na ficha |
| Pagamentos / recibos | Faturação → Pagamentos / Recibos |
| Fila | Fila de espera (F5 actualiza) |
| Triagem | Check-in / triagem |

## Atalhos

| Tecla | Acção |
|-------|--------|
| F2 | Novo paciente |
| F3 | Nova fatura |
| F4 | Pagamentos |
| F5 | Actualizar fila |
| Esc | Limpar selecção (atendimento rápido) |
| Ctrl+P | Imprimir (quando a página o suporta) |

## Erros comuns

- **Fatura sem paciente ou sem serviço** — seleccionar ambos antes de guardar.
- **Redução sem motivo** — preencher motivo; «Outro» exige observação.
- **Confundir saldo com desconto** — saldo é o que falta pagar; redução é diferença oficial vs cobrado.
- **Serviço que não aparece** — só catálogo **operacional** (V1); pedir ao administrador se faltar item.

## Pedir suporte

1. Anotar **hora**, **ecrã** e **mensagem** exacta.
2. Registar em [UAT_ISSUES_SAUVIDA.md](UAT_ISSUES_SAUVIDA.md) durante piloto.
3. Contacto técnico: *preencher na clínica* (telefone/Telegram).

## Terminar sessão

Menu **Sair** / fechar browser. Não deixar sessão aberta em PC partilhado.

## Segurança

- Palavra-passe pessoal; alterar se suspeita de compromisso.
- Não fotografar ecrãs com dados de pacientes para redes sociais.
- Imprimir apenas o necessário; recolher papel da impressora.
