# Reconciliação de preçários SauVida

O novo preçário fotográfico **não** substitui o V1.

| Estado | Significado |
| --- | --- |
| IGUAL | Preço V1 = preço da nova fonte |
| PRECO_DIFERENTE | Ambos existem e diferem — `AGUARDA_VALIDACAO_CLINICA` |
| NOVO_SERVICO | Na foto, ausente no V1 (ex.: Pediatria, Hidrocele, Circuncisão) |
| SERVICO_AUSENTE_NOVA_FONTE | No V1, não listado na foto |
| NOME_DIFERENTE | Correspondência por alias, grafia diferente |
| REVISAR | Nome reconhecido no V1 mas preço da foto ainda não transcrito |

Faturas antigas não são alteradas. `SAUVIDA_V1_1` só com decisão confirmada.
