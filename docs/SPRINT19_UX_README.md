# Sprint 19 — Experiência de utilização (UX operacional)

Sprint focada em **produtividade diária** sem novos módulos nem alteração de contratos API/RBAC.

## Entregas principais

| Área | Melhoria |
|---|---|
| Recepção | Página `/reception/atendimento` — fluxo rápido, atalhos F2–F5 |
| Faturação | Nova fatura em duas colunas, resumo fixo, pesquisa de paciente |
| Médico | Painel com KPIs, próximo paciente, fila |
| Director | KPIs financeiros, serviços mais vendidos |
| Laboratório | Filtros rápidos e acções na tabela de resultados |
| Paciente | Tabs PT, linha temporal no resumo |
| Fila | Badges de estado com cores operacionais |
| Impressão | `PrintDocumentFrame` reutilizável |
