# Manual da Receção — SGCS SauVida

## Atendimento rápido

1. Abra **Atendimento rápido** no menu ou `/reception/atendimento`.
2. Pesquise o utente por **nome**, **telefone** ou **n.º de processo** (mínimo 2 caracteres).
3. Se não existir, use **Novo paciente** (atalho **F2**).
4. **Nova fatura** (**F3**) — seleccione serviços do catálogo V1, reduções se necessário, **Guardar** ou **Guardar e receber pagamento**.
5. Emita o **recibo** na ficha da fatura após pagamento.
6. **Encaminhe** para consulta ou laboratório na fila / encaminhamentos.

## Atalhos de teclado (recepção)

| Tecla | Acção |
|---|---|
| F2 | Novo paciente |
| F3 | Nova fatura |
| F4 | Pagamentos |
| F5 | Actualizar fila |
| Esc | Limpar selecção (atendimento rápido) |
| Ctrl+P | Imprimir (quando disponível na página) |

## Fila de espera

Estados visuais: **Aguardando**, **Em triagem/chamado**, **Na consulta**, **Concluído**. A fila actualiza automaticamente a cada 15 segundos.

## Boas práticas

- Confirme sempre o **preço oficial** vs **valor cobrado** antes de guardar.
- Indique **motivo** em todas as reduções.
- Não altere preços no catálogo — use redução na fatura.
